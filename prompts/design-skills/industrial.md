# industrial

**Source:** `frontend-design` sanctioned direction "industrial /
utilitarian". Governed by `frontend-design.md`.

Function-first, engineered, honest. Data-dense, no decoration for its
own sake. Distinct from `brutalist`: industrial is *clean utilitarian*,
not raw/aggressive.

## Visual rules (intended contract)

- **Neutral palette.** Concrete grey, off-white, safety-accent
  (amber or signal-orange) used only for action/alerts.
- **Grotesque + mono.** Neutral grotesque for headings, monospaced for
  data/labels/specs. Tight, functional sizing.
- **Engineered grid.** Visible modular grid, tabular numerals, spec
  tables, measured rules and reference labels.
- **Zero ornament.** No shadows, minimal radius (0-2px), borders carry
  hierarchy. Dense but legible.
- **Minimal motion.** Instant or very short eased state changes; motion
  only for feedback.

## Banned

- Inter / Roboto / system fonts; purple-on-white gradients.
- Decorative imagery, soft pastels, playful rounding, glow.
- Marketing fluff layouts (oversized empty hero).

## Good for

Manufacturing, logistics, B2B tooling, engineering & construction,
technical services, hardware, data/analytics products.
